# サイトマップ

## 公開サイト（Next.js）

| パス | ページ名 |
|------|----------|
| `/` | トップ |
| `/about` | 会社紹介 |
| `/business` | 事業紹介 |
| `/culture` | 働く環境 / 制度 |
| `/members` | 社員紹介一覧 |
| `/members/[slug]` | 社員紹介詳細 |
| `/jobs` | 募集職種一覧 |
| `/jobs/[slug]` | 募集職種詳細 |
| `/news` | お知らせ一覧 |
| `/news/[slug]` | お知らせ詳細 |
| `/faq` | FAQ |
| `/entry` | 応募フォーム |
| `/entry/confirm` | 応募確認 |
| `/entry/thanks` | 応募完了 |
| `/contact` | 問い合わせフォーム |
| `/contact/thanks` | 問い合わせ完了 |
| `/privacy` | プライバシーポリシー |

| パス | ページ名 |
|------|----------|
| `/admin/login` | ログイン |
| `/admin` | ダッシュボード |
| `/admin/jobs` | 求人一覧 |
| `/admin/jobs/create` | 求人作成 |
| `/admin/jobs/[id]/edit` | 求人編集 |
| `/admin/members` | 社員一覧 |
| `/admin/members/create` | 社員作成 |
| `/admin/members/[id]/edit` | 社員編集 |
| `/admin/news` | お知らせ一覧 |
| `/admin/news/create` | お知らせ作成 |
| `/admin/news/[id]/edit` | お知らせ編集 |
| `/admin/applications` | 応募者一覧 |
| `/admin/applications/[id]` | 応募者詳細 |
| `/admin/inquiries` | 問い合わせ一覧 |
| `/admin/inquiries/[id]` | 問い合わせ詳細 |
| `/admin/media` | 画像管理 |
| `/admin/settings` | サイト設定 / 管理者設定 |
