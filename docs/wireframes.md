# ワイヤーフレーム仕様書

各ページのレイアウト・セクション構成・CTA 配置・コンテンツ優先順位を ASCII ワイヤーフレームで定義する。

---

## 共通パーツ

### ヘッダー（公開サイト）

```
┌────────────────────────────────────────────────────────────────┐
│ CORP.            会社紹介 事業紹介 働く環境 社員紹介           │
│                  求人一覧 お知らせ FAQ        [エントリー ▶]   │
├── Mobile ──────────────────────────────────────────────────────┤
│ CORP.                                               [☰]       │
│  └→ 展開: フルスクリーンオーバーレイ + スクロールロック        │
└────────────────────────────────────────────────────────────────┘
```

- **固定位置**: sticky top-0
- **CTA**: 右端「エントリー」ボタン（常時表示・青背景）
- **モバイル**: ハンバーガー → オーバーレイメニュー（アニメーション付き）

### フッター（公開サイト）

```
┌────────────────────────────────────────────────────────────────┐
│ bg-gray-900                                                    │
│                                                                │
│ CORP.         │ 企業情報      │ 採用情報      │ その他          │
│ テクノロジーで │ 会社紹介      │ 募集職種      │ お知らせ        │
│ 未来を創る     │ 事業紹介      │ 社員紹介      │ FAQ             │
│               │ 働く環境      │ エントリー    │ お問い合わせ    │
│               │               │               │ プライバシー    │
│                                                                │
│ ─────────────────────────────────────────────────              │
│ © 2026 Modern Corp.                                            │
└────────────────────────────────────────────────────────────────┘
```

### パンくずリスト

```
ホーム > 親ページ名 > 現在のページ名
```

- 全下層ページで共通使用
- リンク色: テキスト + ホバーで青
