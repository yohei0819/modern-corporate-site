# Laravel API 指示

## フレームワーク

- Laravel 11.x
- PHP 8.3
- MySQL 8.x
- Laravel Sanctum（SPA 認証）

## ディレクトリ設計

- `app/Http/Controllers/Api/` — 全コントローラーを Api 名前空間に置く
- `app/Http/Requests/` — FormRequest バリデーション（コントローラーにバリデーションロジックを書かない）
- `app/Models/` — Eloquent モデル
- `app/Services/` — ビジネスロジック（Controller が肥大化する場合のみ使用）
- `app/Mail/` — Mailable クラス
- `database/migrations/` — マイグレーション
- `database/seeders/` — シーダー（開発用ダミーデータ含む）
- `database/factories/` — ファクトリー

## API 設計規約

- RESTful なリソース URL を使う
- 公開 API: `/api/jobs`, `/api/members`, `/api/news`, `/api/applications`, `/api/inquiries`
- 管理 API: `/api/admin/applications`, `/api/admin/inquiries`, `/api/admin/media`
- 認証 API: `/api/login`, `/api/logout`, `/api/me`
- レスポンスは Laravel API Resource を使って整形する
- ページネーションは Laravel デフォルトを使う
- 公開側の一覧 API は `status = 'published'` のみ返す（scope で定義）

## バリデーション

- 全リクエストに FormRequest を使う
- バリデーションメッセージは日本語にする（`lang/ja/validation.php`）
- ファイルアップロードは `mimes` / `max` を必ず指定する

## 認証

- Sanctum SPA 認証（Cookie ベース）
- `config/cors.php` で `supports_credentials: true`、`allowed_origins` にフロントの URL を設定
- `config/sanctum.php` で `stateful` にフロントのドメインを設定
- 管理 API は `auth:sanctum` ミドルウェアで保護

## モデル

- `$fillable` を明示する（`$guarded` は使わない）
- リレーションを定義する（`Application belongsTo Job` 等）
- 公開用スコープ: `scopePublished($query)` を各モデルに定義
- slug 検索用: `getRouteKeyName()` で `slug` を返す（公開側で使うモデル）

## シーダー

- 開発用にリアルなダミーデータを入れる
- Factory を使って各テーブルに 10〜20 件
- 管理者ユーザー: `admin@example.com` / `password`

## メール

- `ApplicationReceived` — 応募者への自動返信
- `AdminNotification` — 管理者への通知
- `InquiryReceived` — 問い合わせ管理者通知
- 開発中は `MAIL_MAILER=log` で確認

## ファイルストレージ

- アップロード先: `storage/app/public/`
- `php artisan storage:link` で公開ディレクトリにシンボリックリンク
- 保存パス: `media/`, `resumes/`, `members/`
- ファイル名はユニーク化する（UUID or タイムスタンプ）

## エラーハンドリング

- API は常に JSON レスポンスを返す
- `Accept: application/json` ヘッダーを前提とする
- 404 / 422 / 401 / 403 / 500 の各レスポンス形式を統一する
