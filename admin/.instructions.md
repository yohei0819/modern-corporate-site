# Vue 管理画面指示

## フレームワーク

- Vue 3.5.x + Vite
- TypeScript strict モード
- Tailwind CSS 4.x
- Pinia（状態管理）
- Vue Router 4.x
- Axios

## コンポーネント設計

- Composition API + `<script setup lang="ts">` を必ず使う（Options API 禁止）
- SFC（Single File Component）で `.vue` ファイルに template / script / style をまとめる
- `components/ui/` — Button, Input, Select, Badge, Modal 等の汎用 UI
- `components/forms/` — フォーム系（JobForm, MemberForm 等）
- `components/tables/` — テーブル系（DataTable, Pagination）
- `components/modals/` — モーダル系（ConfirmModal, ImagePickerModal）

## レイアウト

- `layouts/AdminLayout.vue` — サイドバー + ヘッダー + コンテンツ領域
- `layouts/AuthLayout.vue` — ログイン画面用（サイドバーなし）

## ルーティング

- `router/index.ts` に全ルートを定義
- 認証ガードは `beforeEach` で `auth` ストアをチェック
- 未認証なら `/admin/login` にリダイレクト
- ログイン済みでログインページにアクセスしたら `/admin` にリダイレクト

## 状態管理 (Pinia)

- `stores/auth.ts` — ログインユーザー / 認証状態
- `stores/jobs.ts` — 求人一覧キャッシュ
- `stores/applications.ts` — 応募一覧
- ストアは必要に応じて追加。1 ドメイン 1 ストア

## API 通信

- `services/api.ts` に Axios インスタンスを作成
- `baseURL` は環境変数 `VITE_API_URL` から取得
- `withCredentials: true` を設定（Sanctum Cookie 認証）
- リクエスト前に `GET /sanctum/csrf-cookie` を叩く処理を入れる
- レスポンスの 401 はインターセプターでキャッチしてログイン画面にリダイレクト

## フォーム

- バリデーションはサーバー側 FormRequest に任せる
- 422 レスポンスのエラーメッセージをフォームの各フィールドに表示する
- 送信中はボタンを disabled + ローディング表示
- 画像アップロードは `FormData` で送信

## テーブル

- 一覧画面は DataTable コンポーネントを共通化
- ソート / 検索 / ページネーション対応
- ステータスは色付き Badge で表示

## 画像アップロード

- ドラッグ & ドロップ対応
- プレビュー表示
- ファイルサイズ / 拡張子のクライアント側チェック
