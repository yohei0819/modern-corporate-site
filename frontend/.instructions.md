# Next.js 公開サイト指示

## フレームワーク

- Next.js 15.x (App Router)
- TypeScript strict モード
- Tailwind CSS 4.x

## ルーティング

- `app/` ディレクトリの file-based routing を使う
- 動的ルートは `[slug]` を使う（`[id]` ではない。公開 URL はスラッグベース）
- レイアウトは `app/layout.tsx` に共通ヘッダー・フッターを置く
- ページグループが必要なら route groups `(group)/` を使う

## データ取得

- Server Components をデフォルトにする
- API からのデータ取得は `lib/api.ts` の共通関数を使う
- `fetch()` に `next: { revalidate: 60 }` 等の ISR 設定を明示する
- Client Component は `'use client'` ディレクティブを明示する
- Client Component は必要最小限にする（フォーム、フィルタ、アコーディオン等）

## コンポーネント設計

- `components/common/` — Button, Card, Badge, Pagination 等の汎用 UI
- `components/layout/` — Header, Footer, Breadcrumb
- `components/top/` — トップページ専用セクション
- `components/jobs/` — 求人系
- `components/members/` — 社員系
- `components/news/` — ニュース系
- `components/forms/` — フォーム部品

## フォーム

- 応募フォーム / 問い合わせフォームは Client Component
- バリデーションはクライアント側でも行い、サーバー側の FormRequest と二重チェック
- 確認画面パターン: 入力 → 確認 → 送信 → 完了
- 送信中はボタンを disabled にしてローディング表示

## API 接続

- `lib/api.ts` に base URL と共通ヘッダーを定義
- 環境変数: `NEXT_PUBLIC_API_URL`（クライアント用） / `API_URL`（サーバー用）

## SEO

- 各ページで `metadata` をエクスポートする
- 動的ページは `generateMetadata()` を使う
- OGP 画像はデフォルトを設定し、各ページで上書き可能にする

## 画像

- `next/image` を使う
- 外部画像は `next.config.ts` の `images.remotePatterns` に追加

## エラー処理

- `app/not-found.tsx` でカスタム 404
- `app/error.tsx` でエラーバウンダリ
- `app/loading.tsx` でローディング UI
